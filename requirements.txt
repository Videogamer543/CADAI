# Knowledge-base ingestion (tools/kb_ingest.py). beautifulsoup4 gives clean
# article text out of a web page; without it the tool falls back to a regex
# stripper that works but keeps more navigation junk. pypdf is only needed if
# you ingest PDFs. Both are small and neither is imported by the server, so a
# failed install here cannot stop the app from starting.
beautifulsoup4>=4.12
# 4.0 is the floor because that is where extract_text(extraction_mode="layout")
# arrives, and app/pdftext.py needs the layout to see column gutters, running
# headers and table rows. An older pypdf still works -- it says so in the
# warnings and falls back to flat extraction -- but two-column PDFs then come
# out interleaved.
pypdf>=4.0

# Python halves would promise a feature that then fails at run time on a
# machine that looks correctly set up. tools/kb_ingest.py pdfcheck reports
# whether OCR is available and names exactly what is missing.
